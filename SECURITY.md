# Security Policy

## Supported releases

Security fixes are made for the latest stable [Docking release](https://github.com/edumucelli/docking/releases/latest).

## Reporting a vulnerability

Use **Report a vulnerability** on the [GitHub Security Advisories page](https://github.com/edumucelli/docking/security/advisories)
when the option is available. You can also email the [Docking maintainer](mailto:hello@docking.cc).
Keep vulnerability reports private while the maintainer investigates and
coordinates disclosure with you.

Include the affected Docking version, operating system and desktop backend,
steps to reproduce the problem, and its impact. If you share logs or a
diagnostics report, remove credentials and other personal information first.

Report ordinary bugs through [GitHub Issues](https://github.com/edumucelli/docking/issues).
